# Contributing to Splash Monitor ⚡️

Thank you for your interest in contributing to **Splash Monitor**!

## How to Contribute
1. **Fork the repository** on GitHub.
2. **Clone your fork**:
   ```bash
   git clone https://github.com/<your-username>/SplashMonitor.git
   cd SplashMonitor
   ```
3. **Create a branch**:
   ```bash
   git checkout -b feature/my-new-feature
   ```
4. **Make your changes** and test with `./scripts/build_app.sh`.
5. **Commit your changes**:
   ```bash
   git commit -m "feat: add awesome feature"
   ```
6. **Push to your fork** and open a **Pull Request**.

## Guidelines
- Follow Swift modern concurrency conventions (`async/await`, `@MainActor`).
- Keep UI components clean and native in SwiftUI with support for both Light and Dark mode.
- Maintain bilingual support (`tr(es:en:)`) for any new user-facing strings.
